# Phase 4 - Project Planning - EduGenie

## Project Goal
Build AI Learning Assistant using Google Gemini to explain topics, answer QnA, generate quizzes and learning paths.

## Tech Stack
- Backend: Python, Flask
- AI: Google Gemini API
- Frontend: HTML, CSS, JavaScript (templates folder)
- Modules: explanation_module.py, qna.py, quiz_generator, learning_path.py
- Deployment: GitHub
